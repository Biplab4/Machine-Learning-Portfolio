# 📊 Machine Learning Algorithms Lab & Implementation

Welcome to my **Machine Learning Lab Repository**. This project tracks my practical implementations, algorithm mechanics, and Jupyter Notebook pipelines constructed during the **Machine Learning A-Z** curriculum by Kirill Eremenko & Hadelin de Ponteves.

The goal of this repository is to demonstrate an end-to-end understanding of predictive modeling, feature engineering, dimensional transformations, and neural networks.

---

## 🛠️ Repository Architecture & Modules

The repository is structured into distinct algorithmic domains, containing Jupyter Notebooks (`.ipynb`) and clean dataset references:

```text
Machine-Learning-Portfolio/
├── Data Preprocessing/      # Imputation, Encoding, Train-Test Splits
├── Regression/              # Linear, SVR, Decision Trees, Random Forests
├── Classification/          # Logistic, SVM, Naive Bayes, K-NN
├── Clustering/              # K-Means, Hierarchical Clustering

├── Reinforcement Learning/  # UCB & Thompson Sampling
├── Natural Language Processing/ # Text Preprocessing & Vectorization
├── Deep Learning/           # Artificial & Convolutional Neural Networks
